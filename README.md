# EcoWatt – Energy Consumption Monitor

EcoWatt is a web-based energy monitor that helps households and businesses see how much electricity they use, when they use it and what it costs, so they can waste less and save money.

This repository contains the **frontend prototype** built for **DAT709 / PROF709 The IT Professional – Capstone A** by **Team Current Crew**. All energy data in this version is simulated.

---

## Features

**Public website**
- Homepage explaining what EcoWatt does, for homes and businesses
- Navigation bar with six dropdown menus leading to 23 information pages
- Site search that lists matching public pages
- Mobile-friendly layout with a ☰ menu on smaller screens
- Energy Calculator to estimate an appliance's running cost
- Log In and Get Started (register) pages

**Private Energy Dashboard**
- **Overview:** live power (kW), energy used today (kWh), estimated cost and CO₂ for seven appliances that can be switched on or off
- **Analytics:** usage charts by Day, Week or Month, with the peak highlighted
- **Alerts:** a user-set power limit, a warning when usage goes above it, and an alert history
- **Goals:** a monthly kWh target with a progress bar, saved in the browser

## How to Run

No installation is needed.

**Option 1: open it directly**
1. Download or clone this repository.
2. Double-click `index.html` to open it in your browser.

**Option 2: VS Code with Live Server (recommended)**
1. Open the repository folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

**Viewing the dashboard**
1. Click **Log In** at the top of any page.
2. Click the **demo preview** button.
3. The dashboard opens. Opening `dashboard.html` directly will redirect you to the login page.

## Editing the Pages

The header, navigation and footer of the public pages are generated by `build/build.py`.

- To change the **page content**, edit the text inside the `<main>` section of each page.
- To change the **header, menu or footer** on every page, edit `build/build.py`, then run:

```bash
python build/build.py
```

**Note:** running the build script rewrites every public page, so any content edited directly in the pages will be replaced. Agree with the team before running it.

## Known Limitations

- All energy data is **simulated**. Cost uses a placeholder rate of $0.32 per kWh and CO₂ uses 0.7 kg per kWh.
- The login and register forms are **design only** and do not create real accounts.
- Users cannot yet add their own appliances.
- Some information pages still contain placeholder content.
- The footer shows incorrect team member names and placeholder contact details.
- There is no skip-to-content link yet.
