
# Eco Watt Monitor – Testing

## 1. Purpose
Testing ensures that Eco Watt Monitor displays energy information accurately and works correctly.

## 2. Features Tested

| Feature | Test | Expected Result |
|---|---|---|
| Energy Tracking | View usage information | Usage details are displayed |
| Appliance Monitoring | View appliance information | Appliance details are displayed |
| Energy Calculator | Enter watts, hours and electricity rate | Energy usage and estimated cost are calculated |
| Energy-Saving Targets | Set a consumption goal | The target can be recorded |
| Consumption Warnings | Exceed a set goal | A warning should appear if implemented |

## 3. Testing Method
Test each feature using sample data and compare the results with expected outcomes. Check that invalid inputs are handled appropriately.

## 4. Results
Record each test as Pass or Fail after performing it. Do not mark tests as passed until they have been completed.

## 5. Conclusion
Testing helps identify errors and improve the reliability and usability of Eco Watt Monitor.
